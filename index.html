📲 Phone Mein App Install Karne Ka Tareeqa

Android Phone (Chrome):

1. Upar right corner mein 3 dots (⋮) par tap karein.

2. Menu mein "Install app" ya "Add to Home screen" (होम स्क्रीन पर जोड़ें) select karein.

3. "Add / Install" dabayein — aapke mobile ke app drawer aur screen par app icon aa jayega!


iPhone (Safari):

1. Neeche Share button (⎋) dabayein.

2. "Add to Home Screen" par tap karein.

📊 Google Sheet Connect Guide

Google Sheet mein app se direct data likhne ke liye Google ki privacy setting ke mutabiq ye 1-minute ka chhota sa code lagana hota hai:

Step 1: Apni Google Sheet kholein

Apne computer ya phone browser mein apni Google Sheet kholein.

Step 2: Extensions > Apps Script kholein

Top menu mein Extensions (एक्सटेंशन) par click karein aur Apps Script chunein.

Step 3: Ye Code Paste Karein
Step 4: Deploy > New Deployment

Upar blue Deploy button dabayein -> New deployment -> Select type: Web App -> Who has access: Anyone -> Deploy daba kar URL copy karein aur app mein paste karein!
